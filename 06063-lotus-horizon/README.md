## GitHub Pages 部署（约 3 分钟，无需令牌）

1. GitHub 网页 → 右上角 `+` → **New repository**：填公开仓库名（如 `06063-lotus-horizon-report`），可见性选 **Public**，其余留空 → **Create repository**。
2. 在仓库页把 `index.html` 与 `README.md` **两个文件直接拖进页面** → **Commit changes**。
3. 仓库 **Settings → Pages**：Source 选 **Deploy from a branch**，分支 `main`、目录 `/ (root)` → **Save**。
4. 约 1–2 分钟后，网址即为 `https://<你的用户名>.github.io/<仓库名>/`。
